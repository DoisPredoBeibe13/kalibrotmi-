# Kali Linux Otimizado para Brasileiros 🇧🇷

Script automatizado para deixar o Kali Linux mais rápido, leve e totalmente compatível com **TryHackMe / Hack The Box (VPN)**.

## 🚀 O que ele faz?
* Desativa permanentemente sombras e efeitos visuais pesados (XFCE).
* Otimiza a resposta do processador de acordo com o hardware (Perfis Fraco/Forte para evitar travamentos no i5).
* Melhora o gerenciamento de memória RAM (`swappiness=10`).
* Configura DNS de alta velocidade (Cloudflare/Google) sem quebrar o DNS interno de laboratórios e VPNs.
